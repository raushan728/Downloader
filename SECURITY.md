# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability within DWDR, please do not open a public issue. 
Instead, report it directly to the maintainer via email or utilize the private GitHub vulnerability reporting tool. 

All security issues will be triaged and addressed promptly.
